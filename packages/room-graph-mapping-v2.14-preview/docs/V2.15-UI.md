# Mode + inspector layout (UI prototype)

A layout experiment for usability testing. No editing behaviour changed: every control keeps its id (except the delete-room trash and the per-room connector list, see below), and all handlers are the old ones.

## Structure
- **Toolbar above the plan** (one wrapping row):
  - Undo / Redo (icons);
  - the three map actions *Map* (run mapper), *Close gaps*, *Fit* (fit selected room to neighbours, 0.3 m), each icon + short label;
  - Tool (Move rooms | Drag walls) and Move mode (Free | Slide | Slide + pull) as segmented buttons;
  - zoom out / 100% / zoom in / fit all and the grid select, small buttons;
  - view switch Mapping | Gap;
  - Load JSON / Save graph (icons) on the right.
- **Status bar under the plan:** status message and the joints summary.
- **Background click** on the plan clears the room and connector selection.
- **Sidebar:** mode tabs **Layout | Connectors | Building**, the **inspector** (`#panel`) under the tabs, then the section of the active tab, then a *Settings* drawer.
  - **Inspector:** a selected room shows its name with a trash icon (delete room), the two lock checkboxes and small side-by-side W / H fields that apply when the entry is finished (no Apply button; a hidden `apply-room` button remains only so the old smoke script keeps working). A selected connector shows its card (type, width, door type, hinge / swing / angle, window sill / head, trash icon).
  - **Layout:** *Rooms* with a **+** that opens the add-room panel (name, size, side; closes after a successful add), wall alignments.
  - **Connectors:** show-widths tickbox, a **table of all connectors** (room, side, type, width, partner, trash icon). Tapping a row selects the connector, rings it on the plan and opens its card; the rows of the selected room come first. Below: Align connectors and the connection settings (type, width, door type) used by *Connect* and when adding a room.
  - **Building:** only the building values (the inspector and Settings drawer are hidden in this tab).
- Selecting a connector on the plan or in the table switches to the Connectors tab (only when the selection changes).
- **Classic layout** checkbox: shows all sections stacked and the two selects instead of the segmented buttons, for comparison.

## Icons
Inline SVG sprite at the top of the sidebar (`<symbol id="i-...">`, 24x24, stroke icons using `currentColor`) and `<svg class="ic"><use href="#i-name"/></svg>` in the buttons. Names: undo, redo, zin, zout, fit, trash, map, gaps, fitn, load, save. To change an icon, replace the `<path>` of its symbol in `src/editor.ts`.

## Not done on purpose
- No Export tab: only JSON load / save exist, so they stay in the toolbar.
- The connector table is read-only; edit values in the card.

## Tests
`test/layout.test.ts` (control ids exactly once, tabs, sections, toolbar order, inspector outside the sections, status bar position) and layout scenarios in `scripts/browser-smoke-connectors.mjs` (tabs, segmented buttons, auto-switch, classic toggle, connector table + ring, background click, trash, auto-applied W / H, add-room panel). CSS and the actual look are not covered by tests: judge them in the browser.
