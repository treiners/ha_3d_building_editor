# Foundation for shared walls, sliding and auto-resize (Phase 0)

Goal of the next phases: rooms stay attached to their neighbours while they are moved, can slide along the shared wall, and non-fixed rooms may resize to fit. Phase 0 adds the building blocks only. **No existing editing behaviour changed.**

## Joints (`src/joints.ts`, `deriveJoints`)
A joint is the state of one shared wall, derived from a relationship (`A.right <-> B.left`).
- `status`: `ok` (same rule as the editor's own green/red connector check: walls touch within 0.08 m with a positive shared part, and the two connector points are within 0.2 m), `broken` (reasons: `gap`, `no-overlap`, `misaligned`), `detached` (user choice), `invalid` (unknown connector, same room, non-opposing sides), `unplaced` (a room has no layout). A test compares the ok-count with the editor's own count over hundreds of random edits, so the two cannot drift apart.
- `narrow` / `touching`: the shared part being smaller than opening width + 0.1 m is reported separately (`narrow`) and never changes the status.
- Geometry: `gap` (signed), `overlap` (shared interval, world coordinates), `axis` (direction of the wall), `opening` (world position), `openingAligned`.
- `slide`: how far room B may move along the wall (`min`/`max`, metres) while the shared part stays at least opening width + 0.1 m; `fixedOpening` is the narrower range that also keeps the opening where it is. Shifting room A by -s is equivalent.
- `movable`: `false` for rooms with `locked`.
- Optional persisted override in the graph: `"joints": [{ "relationshipId": "...", "state": "detached" }]`. Files without it are unchanged; everything is `attached` by default.

## History (`src/history.ts`, `createHistory`)
Snapshot-based undo/redo (limit 100). The editor records a step for: finished drags (room, resize, connector; a click without movement is not a step), Apply room, Align connectors, Run mapper, add/remove wall alignment. Loading a file clears the history. Shortcuts: Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl/Cmd+Y.

## Editor changes
Undo/Redo buttons below *Run mapper*, and a `Joints: N attached[, M broken][, K detached]` line below the status. Both modules are embedded into the generated HTML the same way as `mapLayout`, so Node tests and the browser run identical code.

## Tests
`test/foundation.test.ts` (joint geometry with hand-computed slide ranges, boundary cases, overrides, history, embedding) and the optional `scripts/browser-smoke.mjs` (real drag, undo/redo, keyboard, joint summary in a fake DOM; needs `npm i -D jsdom`).
