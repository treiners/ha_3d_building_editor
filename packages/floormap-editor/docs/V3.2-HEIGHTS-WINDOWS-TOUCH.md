# v3.2 additions: heights, openings, touch, dock, autosave, entities per connector

All additions are optional and additive; files without the new keys behave as before. Overview and state: `docs/HANDOVER-3.2.md`. File keys: `docs/FILE-FORMAT.md`.

## Heights
- `room.elevation` / `area.elevation`: height from floor (m, 0..10, default 0, written only when not 0). Room box > *Heights* card, Site box > *Height from floor*. A raised room or area shows `+0.45 m` only while the **m** toggle is on.
- Wall heights: `room.wallHeights { top, right, bottom, left }`, `room.wallHeight`; resolution wall > room > floor `height` > `buildingDefaults.wallHeight` > 2.4 (`wallHeightOf`). Window sill / head are clamped to the lowest wall height of the pair.
- **Walls mode** (mode switch, last button): rooms read-only; every wall (`roomId:side`) is a strip coloured by height with the value; click (Shift = add), set the height in the wall box (empty = default). A wall touching the facing wall of another room is ONE physical wall, both sides change together (dashed strips); free walls change alone. Shapes: one height per side. Code `src/wallheights.ts`, `src/editor-walls.ts`.
- Contract warnings: `height-elevation-range`, `height-window-above-wall`, `height-shared-wall-height`.
- Not yet: per-segment heights on notch walls, sloped walls, heights in the solver.

## Openings
- Window `type`: `fixed`, `slide-vertical`, `slide-horizontal`, `tilt`, `hinged`, `tilt-turn`; `hinge`, `swing` (hinged, tilt-turn), `slide` (slide-horizontal); written with defaults on save.
- Door `glazing: "glass"`; `door.tilt` (tilt and turn); sliding and pocket doors carry only `door.slide` (`start` | `end`, shown as left / right seen from the room of the selected connector); no hinge / swing / angle. Width follows the door movement (one half slides over the other).
- Plan symbols for the selected connector; rows in the connector box (`src/editor-opening-opts.ts`).
- **Connect to** for an unconnected door / passage: link to a free connector of the neighbour room or create the partner (`src/link.ts`).
- Objects keep only 0.1 m free in front of sliding / pocket doors.

## Entities
- Any number per connector / object. `role` open (default) / tilt for door and window contacts (tilt needs a tilting window or `door.tilt`). Checks `role-mismatch`, `invalid-option`.
- Three or more on one connector = one count badge, hover 0.4 s (or tap) shows them in a ring. Connector box > *Entities* block; objects: *+ other entity...*.

## UI
- Dock: all floating boxes in one scrolling column, title click collapses (remembered). Zoom buttons in the status bar. **T** = show / hide text labels. Autosave in the browser (`?fresh=1` discards).
- **Rename room:** pencil button next to the trash icon in the room box (or F2); Enter confirms, Esc cancels; pure `renameRoom` in `src/rename.ts` (unique name per floor, `Outside` reserved, id unchanged).
- **Toolbar:** Settings > Interface > Toolbar `Grouped` (opt-in): fixed rows, dimmed instead of hidden tools, Issues / Export in `#tb-extra`, zoom + grid in the status bar. Tool hotkeys C (Drag corners), W (Drag walls), S (Shape). No corner handles while Drag walls is active.
- **Object categories** are free text (Types tab), see `docs/V2.17-OBJECTS.md`.
- Touch: one-finger pan on empty background, two-finger pinch + pan, Pan and one-shot Shift buttons, bigger targets, portrait layout. Shift while dragging a room corner locks x / y.

## Planners
- The dragged room stops at its minimum size (a size-locked room is carried). Overlap blocking and touch-gluing use the real shape of rooms with an outline (notches).
