# v2.14 Mapper
The mapper (`src/mapper.ts`, function `mapLayout`) turns a graph without coordinates into a first, non-overlapping floor plan. Precision is not the goal: rooms get default sizes and are refined later by dragging walls and rooms.

Used in two places, with the same code (the generated editor HTML embeds `mapLayout.toString()`):
- **Load JSON / initial generation** (`mapOnlyMissing`): rooms that already have a layout are kept untouched; only rooms without one are placed.
- **Run mapper**: every unlocked room is re-placed (its current size is kept). Locked rooms never move and act as anchors.

Algorithm
1. **Normalise** - default size per `sizeCategory` (small 3x2, medium 4x3, large 6x4 m); connector position is `offset` (metres) or `position` x wall length.
2. **Seed** - per connected component, start at the room with the highest number of required relationships (a fixed room wins). Walk outwards; every room is placed touching its parent on the connector side, shifted along the wall so both connector positions line up. Disconnected components are placed side by side.
3. **Relax** - bounded iterations of springs (touch the partner wall, weak slide along the wall while the opening still fits) plus overlap projection along the axis of least penetration.
4. **Legalise** - snap to the grid, then deterministic coordinate descent on a score: overlaps, unsatisfied or wrong-sided relationships, connector misalignment, total area.
5. **Report** - layouts, issues, metrics and one shared opening point per satisfied relationship; both connectors receive matching metre offsets so the pair is green.

Rules
- Deterministic: same input gives the same output, independent of room and relationship order.
- Only opposing sides (left/right, top/bottom) can share a wall. Other pairs, windows and unknown connectors are reported as issues and ignored for placement.
- A relationship counts as satisfied when the walls touch and the shared interval is at least the opening width (door 0.9 m, open passage 1.2 m).
- Impossible graphs (e.g. A right of B right of C right of A) produce no overlaps and an `unresolved-relationship` issue instead of a faked result.
- The `Outside` room is mapped like any other room; the editor only hides it when drawing.

Known limitation: the final search moves one room at a time. If locked rooms leave no valid space for their neighbours, an overlap can remain and is reported. Moving connected rooms together is the next planned step.
