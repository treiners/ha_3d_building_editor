# Adding and removing rooms and connectors (Phase 3)

Editing the room graph from the floor plan. Rooms stay rectangles. All functions live in `src/edit.ts`: pure, deterministic, they return a NEW graph (the input is never mutated) and are embedded in the HTML like the planners. Each user action is one undo step.

## UI ("Rooms" section in the sidebar)
- **Add room next to selected**: name, size category (small 3x2 / medium 4x3 / large 6x4), wished side, and the connection type (door / open passage / no connection). The room is placed flush against the selected room on the wished side if there is free space (sliding along the wall in 0.2 m steps, keeping a shared part for the door), otherwise on another side (right, bottom, left, top). Without a selected room, or with no free space, it is placed in free space right of the plan and not connected. The new room becomes the selection. The hidden `Outside` room does not block placement.
- **Connect two selected rooms** (click one, shift-click the other): finds the shared wall (walls within 0.08 m, positive shared part) and creates the connector in **both** rooms at the middle of the shared part (same world position, so the pair is green) plus the relationship, in one step. Refused with a message if the rooms do not share a wall, the shared part is shorter than opening width + 0.1 m (door 0.9, passage 1.2), or they are already connected. This is the simple answer to "a new connector also needs a connector in the connected room": it is always created as a pair.
- **Delete selected room**: removes the room, its connectors and relationships, the matching joint overrides, and the room from wall alignments (a group left with fewer than two rooms is dropped). Connectors of neighbours that lost their partner stay and show orange (not connected); the message says how many.
- **Connectors list** in the room panel: each connector with its side, type and partner, and a **Remove** button that removes the pair and the relationship.

Ids: room id = slug of the name (`kitchen`, `kitchen-2`); connector id = `<room>-<side>-<type>` (suffix `-2` ... when taken); relationship id = `<connectorA>--<connectorB>`.

## Not covered yet
- Connectors to the `Outside` room (exterior doors) and windows cannot be created here yet; the hidden Outside room cannot be selected.
- Changing the type or position of an existing connector (drag it along the wall as before; remove and connect again to change the type).
- The same editing in the graph editor (connector editor); the schema is unchanged, so both can write the same files.
