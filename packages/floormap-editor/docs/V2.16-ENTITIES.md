# Entity placement mode (lights, motion sensors, door contacts)

A second mode in the same editor (`Floor plan | Entities` switch at the top of the sidebar) for placing entities on the finished plan, as the link to Home Assistant. In entity mode the floor plan is **read-only**: no moving rooms, walls, corners or connectors, no mapper / Close gaps / Fit. Undo / redo, zoom, fit, grid, load and save stay available. The Gap view is hidden.

## Data (all keys optional; files without them behave as before, `schemaVersion` stays `2.14`)
```json
"entitySettings": { "coordinates": "room", "gridStep": 0.1 },
"entityPlacements": [
  { "id": "living-ceiling-light", "type": "light", "roomId": "living", "position": [2.2, 1.3], "height": 2.2 },
  { "id": "living-motion-sensor", "type": "motion-sensor", "roomId": "living", "position": [0.2, 1.1], "height": 2.1,
    "facingDegrees": 90, "fieldOfViewDegrees": 100, "range": 3.5 },
  { "id": "bedroom-door-contact", "type": "door-contact", "connectorId": "bedroom-front-left-door" }
]
```
- **Anchor:** exactly one of `roomId` or `connectorId`. A connector entity sits on the connector point.
- **Coordinates:** `position = [x, y]` in metres from the room's top-left corner (x right, y down). World position = room corner + position, so the plan can still be changed in floor-plan mode. `entitySettings.coordinates: "plan"` means global positions: the editor converts them to room-relative on load (and saves `"room"`); the setting is never guessed.
- **Orientation:** `facingDegrees` clockwise from up (north, -y): 0 = up, 90 = right. `fieldOfViewDegrees` is the full opening angle (10..360), `range` in metres (0.5..30).
- **Height:** metres above the floor, clamped to 0..`wallHeight`. Defaults: light 2.2, motion sensor 2.1.
- **Ids:** slug (`<room>-<type>`, `-2` suffix on clash), editable; optional `name` and `haEntityId` (the Home Assistant entity id).
- **Types** (`entityCatalog()` in `src/entities.ts`, data-driven): `light`, `motion-sensor` (directional), `environment-sensor` (`measures`: any of temperature, humidity, co2, illuminance, pressure, voc; default temperature + humidity), `smoke-detector` (smoke / fire), `water-leak` (height 0.1 m) are room entities; `door-contact` (door connectors) and `window-contact` (window connectors) are connector entities, one per connector (a contact on each end of the same door is flagged).
- **Save** writes every default explicitly (`fillEntityDefaults`); a graph without entities is unchanged.
- **Resizing a room** (`entitySettings.resize`, sidebar select *On room resize*): `"proportional"` (default) scales room-anchored positions by newSize / oldSize per axis from the top-left corner, so a light in the bottom-right corner stays in the bottom-right corner. `"anchor"` keeps the distance to a corner instead (the nearest corner, or the entity's own `anchorCorner` `tl` / `tr` / `bl` / `br`, set in the inspector in this mode), clamped into the room. Applies to every resize path (corner handles, walls, Apply, Fit, Close gaps, Map, ...). Moving a room changes nothing. `syncEntitySizes` runs on every render in both modes and is part of the same undo step as the resize. Save rounds positions to 4 decimals.
- **Integrity:** deleting a room removes its entities and those on its connectors; removing a connector removes the entities bound to it (status: "N entities removed"; undo restores).

## Using it
- **Place tab:** pick a type, then click in a room (grid 0.1 m, Alt = free, Shift = keep placing, Esc = cancel). Door contacts: click a highlighted door.
- **Select:** click an entity (or a row in the List tab, which rings it on the plan). Drag to move; dropping into another room re-parents it. Arrow keys nudge by the grid (Shift = x5), Delete removes.
- **Motion sensor:** the selected sensor shows its coverage cone with three handles (facing, range, field of view; 5 degree steps, Alt = free). *Show coverage* draws the cones of all sensors.
- **Inspector:** name, id, HA entity, x / y, height, facing, field of view, range (trash icon removes).
- **List tab:** table (name, type, parent, HA id, warning), filters by room and type, collapsible diagnostics (unknown type, orphan, outside room, height range, duplicate id, type mismatch, double contact).
- One undo step per finished gesture or field edit.

## Code
`src/entities.ts` (pure, embedded into the HTML with `toString()`, sibling global `entityCatalog` only), `src/edit.ts` (cascade), `src/editor-entities.ts` (CSS / HTML / JS of the mode) plus a few hooks in `src/editor.ts` (imports, embed list, CSS / switch / sidebar / script insertion, early return in the floor-plan `pointerdown`, `entLoad()` on load, `fillEntityDefaults` on save).
Tests: `test/entities.test.ts` (hand-computed cases, embedded-source parity, HTML structure) and `scripts/browser-smoke-entities.mjs` (jsdom: lock, place, undo, handles, door contact, re-parent, inspector, List tab).
