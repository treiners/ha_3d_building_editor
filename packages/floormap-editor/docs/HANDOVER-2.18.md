## 4. Things learned (gotchas)
- The page script is dense JS in template literals: edit with exact-substring replacements, rebuild, test. New page code must not contain backticks or dollar-brace and must not repeat `ignoreIds:hidden()` (the golden test counts it: 7; call `hidden()` into a variable).
- Pure functions are pasted into the page with `toString()`: no value imports in their bodies, siblings must be in `src/embed.ts` (and in the fixed function lists of older tests such as `test/entities.test.ts`). Explicit `any` budget per source file (`test/any-budget.test.ts`): type new code, never loosen the guard.
- Geometry of shapes: `outlineWalls(o)[i].side` is the direction a wall faces; **two walls facing the same way can cover the same offset** (outer wall + notch wall): `outlineWallAt(o, side, along, at?)` takes the outermost unless `at` (a connector's `wallAt`) names the other. `reshapeRoom` keeps the wall a connector sits on. A shape must have no wall shorter than 0.3 m and no part thinner than 0.3 m.
- A real shape is size-locked (set on load, on save and by `reshapeRoom`); planners then carry it as a whole.
- Existing tests that count UI elements (`layout.test`, `boxes.test`) are updated for new buttons / boxes; that is intended, say so when it happens.
- The Filesystem tools sometimes time out (approval prompt in the Claude Desktop app or a stuck MCP server): check the file on disk before repeating an edit, never repeat an insert blindly.
