# Interactive Openings Editor v1.3

Combines selectable connector/window targets with constrained movement along the current boundary.

## Capabilities
- Inspect rooms, walls, connectors and windows.
- Large transparent click targets for narrow openings.
- Change connector/window offset in metres.
- Preview movement immediately.
- Download the updated building JSON.

## Constraints
- Movement stays on the existing boundary.
- Width and boundary assignment are unchanged.
- The editor does not automatically re-run validation in-browser. Run the v1.1 validator against downloaded JSON before accepting changes.
