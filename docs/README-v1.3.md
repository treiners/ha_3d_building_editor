# Interactive Openings Editor v1.3

This package combines the planned v1.3 selection work and v1.4 constrained movement work.

```bash
npm test
npm run build
node dist/examples/reference-apartment-openings-editor.js examples/reference-apartment-v1.2.json
open examples/reference-apartment-openings-editor.html
```

Click a connector or window, change its offset, apply the change, then download updated JSON. Validate the downloaded JSON with the v1.1 validator.
