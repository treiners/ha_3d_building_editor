# Architectural Symbol Rules v1.4

- Symbols are abstract and communicative, not CAD-accurate.
- Hinged doors show a leaf and swing arc.
- External doors use a stronger green leaf.
- Open passages use an amber dashed marker within the resolved gap.
- Windows show permanent blue glazing and two dark-blue frame lines.
- Symbols carry the same inspection IDs as their source connector/window.
- The wall-opening geometry remains authoritative; symbols never alter geometry.
- Transparent editing targets may remain above symbols for easier pointer interaction.
